# Contributor Covenant Code of Conduct

We are committed to providing a welcoming and harassment-free experience for everyone. Be respectful, assume good intent, give constructive feedback, and focus criticism on ideas and code rather than people.

Unacceptable behaviour includes harassment, discriminatory language, personal attacks, deliberate intimidation, and publishing private information without consent.

Project maintainers may remove or reject contributions that do not follow this code. Report conduct concerns privately to the repository maintainers.
